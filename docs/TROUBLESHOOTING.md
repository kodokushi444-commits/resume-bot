# 常见问题和排错

先记住一个原则：

如果黑窗口正在输出文字，通常说明它还在工作。第一次启动可能比较慢，不要急着关。

## 双击后没反应

可能原因：

- 文件还在压缩包里，没有真正解压
- Windows 拦截了脚本
- 杀毒软件拦截

可以这样做：

1. 确认你已经把 ZIP 解压成普通文件夹。
2. 右键 `启动求职助手.bat`。
3. 选择“以管理员身份运行”试一次。
4. 如果杀毒软件弹窗，确认它拦的是你刚下载的本地脚本。

## 提示找不到 Python

说明电脑没有安装 Python，或者安装时没有加入 PATH。

解决办法：

1. 安装 Python 3.11 或更新版本。
2. 安装时勾选 `Add python.exe to PATH`。
3. 安装完成后，重新双击 `启动求职助手.bat`。

如果你已经安装过 Python，但还是失败，最简单的办法是重新安装一次，并确认勾选 PATH。

## 第一次启动很慢

这是正常的。

第一次启动会安装：

- Python 依赖
- Playwright Chromium
- 本地运行环境

如果网络慢，可能需要几分钟。

只要黑窗口还在输出文字，就先等。

## 网页打不开

先看黑窗口里有没有类似这一行：

```text
Local URL: http://127.0.0.1:8765
```

把这个地址复制到浏览器地址栏。

如果还是打不开：

1. 不要关闭黑窗口。
2. 等 20 秒再刷新网页。
3. 如果端口不是 `8765`，以黑窗口显示的地址为准。
4. 如果仍然失败，关闭黑窗口，重新双击启动。

## AI 测试失败

常见原因：

- API Key 填错
- Base URL 填错
- Model 填错
- 网络无法访问模型服务
- Key 没有对应模型权限

建议按这个顺序检查：

1. 重新复制 API Key，确认没有多复制空格。
2. 确认 Base URL 是服务商给的接口地址。
3. 确认 Model 是当前 Key 支持的模型。
4. 先只测试文本模型。
5. 文本模型通过后，再配置视觉/OCR 模型。

## BOSS 没登录

先不要反复点采集。

建议：

1. 用你平时的 Edge 或 Chrome 打开 BOSS。
2. 手动登录。
3. 确认能正常看到岗位搜索页。
4. 回到求职助手网页，再开始采集。

如果出现验证、空白页、频繁失败：

- 停下来
- 手动处理验证
- 不要高频刷新
- 不要把它当成自动化刷页面工具

## 黑窗口停住不知道怎么办

先看最后几行文字。

如果看到：

```text
Local URL: http://127.0.0.1:xxxx
```

说明服务已经启动，黑窗口需要一直开着。

如果看到错误信息：

1. 不要先关窗口。
2. 截图最后 20 行。
3. 去看本文件里对应的问题。
4. 如果要反馈问题，请带上截图。

## 杀毒软件提示风险

这个项目会启动本地网页、安装依赖、调用浏览器自动化组件，所以某些杀毒软件可能会紧张。

建议：

- 只从你信任的 GitHub 仓库下载
- 不要下载别人二次打包的未知版本
- 如果不放心，可以先不运行 BOSS 采集，只打开本地网页和 AI 设置

## 想重新来一遍

如果你只是想重新启动：

1. 关闭黑窗口
2. 重新双击 `启动求职助手.bat`

如果你想清空本地数据，请谨慎处理 `data/` 文件夹。

注意：`data/` 里可能有你的简历、本地数据库、BOSS 登录态和缓存。
