# 新手安装教程

这份教程写给不会开发、没用过 GitHub 的用户。

你只需要会下载文件、解压文件、双击脚本。

## 第 1 步：下载项目

打开项目的 GitHub 页面后，找绿色按钮：

```text
Code
```

点击它，然后点：

```text
Download ZIP
```

浏览器会下载一个压缩包，名字通常类似：

```text
resume-bot-main.zip
```

## 第 2 步：解压

把压缩包解压到一个好找的位置。

推荐：

```text
D:\resume-bot
```

或者：

```text
E:\tools\resume-bot
```

不推荐放在：

```text
桌面
下载
OneDrive
微信文件夹
路径特别长的目录
```

原因是这些位置更容易遇到权限、同步、路径过长的问题。

## 第 3 步：安装 Python

这个版本还没有打包成 exe，所以电脑上需要安装 Python。

推荐安装 Python 3.11 或更新版本。

安装时注意勾选：

```text
Add python.exe to PATH
```

如果你已经装过 Python，可以先继续下一步。

## 第 4 步：启动求职助手

进入解压后的项目文件夹。

双击：

```text
start_resume_bot.cmd
```

这个入口最稳，窗口里会显示英文提示。

如果你更喜欢中文文件名，也可以双击：

```text
启动求职助手.bat
```

第一次启动会做这些事：

1. 创建本地运行环境
2. 安装 Python 依赖
3. 安装浏览器自动化组件
4. 启动本地网页

第一次可能要等几分钟。黑窗口不要关。

## 第 5 步：打开网页

正常情况下，浏览器会自动打开网页。

如果没有自动打开，请看黑窗口里的地址，通常长这样：

```text
http://127.0.0.1:8765
```

如果端口被占用，也可能是：

```text
http://127.0.0.1:8766
http://127.0.0.1:8767
```

以黑窗口里显示的地址为准。

## 第 6 步：配置 AI

进入网页左侧的：

```text
AI 设置
```

填写你的文本模型配置：

- Provider
- Base URL
- API Key
- Model

然后点击测试。

测试通过后，再保存。

普通用户不需要先手动编辑 `.env` 文件。网页里填就可以。

## 第 7 步：上传简历

回到首页，上传你的简历文件。

建议先用：

- PDF
- DOCX

如果解析效果不好，可以之后再调整简历格式。

## 第 8 步：设置求职偏好

进入：

```text
求职偏好
```

填写你想看的岗位方向、城市、学历、全职/实习等信息。

不用一次填完。先填最重要的几项就行。

## 第 9 步：登录 BOSS

如果要采集 BOSS 岗位，需要你自己登录自己的 BOSS 账号。

建议先在本机 Edge 或 Chrome 里正常打开 BOSS 并登录。

然后再回到求职助手网页里开始采集。

注意：

- 不要频繁反复采集
- 遇到验证请停下来手动处理
- 不要把它当成自动投递工具

## 第 10 步：采集岗位并查看推荐

推荐流程是：

```text
采集岗位 -> 补抓 JD -> AI 推荐 -> 人工审阅
```

你需要做的是：

1. 设置城市和关键词
2. 点击采集岗位
3. 等待岗位列表出现
4. 点击补抓并推荐
5. 查看推荐结果
6. 自己决定是否打开岗位、收藏或投递

## 下次怎么启动

以后还是双击：

```text
启动求职助手.bat
```

如果启动失败，先看：

- [常见问题和排错](TROUBLESHOOTING.md)
